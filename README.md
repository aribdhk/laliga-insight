# LaLiga Insight — Python-only desktop analytics

## Run
1. Open this `files (1)` folder in VS Code.
2. Install NumPy if needed: `py -m pip install numpy`
3. Run: `py main.py`

## Design
A completely redesigned Tkinter interface: midnight ink surfaces, warm editorial typography, coral and mint accents, custom pitch illustration, navigation rail, data cards, interactive analysis views, custom bar visualizations, sortable-style tables, head-to-head comparisons, and match record management.

## Files
- `main.py` — Python/Tkinter interface and navigation
- `models.py` — match model, CSV persistence, CRUD and filters
- `calculations.py` — NumPy statistics, table and head-to-head analysis
- `validation.py` — validation for match inputs
- `laliga_matches.csv` — original match dataset

No HTML, CSS, JavaScript or JSON is used. The interface is rendered entirely by Python Tkinter.
